# Third-party runtime inputs

The local build uses the upstream Linux/PRoot route for separately selected `x86_64` and `arm64-v8a` APKs. [Input manifest](upstream-inputs.json) pins both architectures' versions, URLs and SHA-256 values for the public `dev.olea` application. Set `OLEA_ABI=arm64-v8a` or `OLEA_ABI=x86_64` when running `runtime/build.sh`; x86_64 remains the default. Each APK contains one selected guest and matching native ABI.

[Upstream checksum excerpts](checksums/2026-11-13-upstream.txt) record the exact Ubuntu/Node checksum lines and Termux package-index stanzas used to establish the pins. These were retrieved from the upstream HTTPS authorities, including both Termux architecture indexes. No independent signing-key or GPG verification is claimed. ELF checks establish archive/native architecture before packaging; APK checks compare packaged archive and native bytes to the verified build inputs.

- Ubuntu Base 24.04.3 amd64/arm64: mixed licenses. Packaged copyright notices remain under the guest `/usr/share/doc` and `/usr/share/common-licenses`. The release source companion supplies all 65 exact source-package versions covering the 91 installed binary packages in each image, with original source, Debian/Ubuntu changes, build rules and source-index hashes.
- Node 24.20.0 Linux x64/arm64: MIT plus bundled notices. Original Node archive bytes are verified before deterministic gzip repackaging; `/opt/node/LICENSE` remains included. The companion includes the complete exact upstream source archive; [Node-LICENSE](licenses/Node-LICENSE) preserves its full license and bundled notices.
- Termux PRoot 5.1.107.102: GPL-2.0-or-later according to source headers. Native bytes are renamed for Android PackageManager extraction, without binary modification. Complete tagged source and the pinned Termux build tree accompany the release. [PRoot-COPYING](licenses/PRoot-COPYING), [GPLv2](licenses/GPL-2.txt) and [GPLv3](licenses/GPL-3.txt) are included. The PRoot/talloc combination uses the GPLv3-compatible route described in the replacement instructions. Source: https://github.com/termux/proot.
- libtalloc 2.5.0: LGPL-3.0-or-later according to `talloc.c`, `talloc.h` and upstream `LICENSE`. Termux labels its package GPL-3.0; retain both [LGPLv3](licenses/LGPL-3.txt) and its incorporated [GPLv3](licenses/GPL-3.txt), with the library's original permissions. The companion includes complete source and Termux recipes. [Replacement instructions](source/RELINKING.md) supply the corresponding PRoot code and a concrete APK recombination/signing route. Modification and reverse engineering to debug library modifications are permitted. Source: https://talloc.samba.org/.
- libandroid-shmem 0.7: BSD-3-Clause. [Full copyright, conditions and disclaimer](licenses/libandroid-shmem-LICENSE) accompany the source and binary notices. Exact source and Termux recipes are in the companion. Source: https://github.com/termux/libandroid-shmem.
- Pi 1.5.2: installed on-device through npm, with its upstream package license and dependency notices. No private agent source fork is included.
- Gradle 9.1.0, Android Gradle Plugin 9.0.0, TypeScript and Node type declarations are build tools, not the app's Linux execution layer.

For public releases, distribute the matching `olea-<version>-runtime-source.tar.gz` and `olea-<version>-runtime-NOTICES.txt` as direct downloads on the same release page as each matching APK, with prominent source/notices links and checksums. [Companion contents and assembly recipe](source/README.md), [source download lock](source/source-lock.json), [full native notices](licenses/NOTICE.md), and [release evidence and remaining gates](../docs/archive/release-0.1.0/0.1.0-redistribution.md) describe this route. It supplies source directly rather than relying on an upstream-only link or future written offer. Preserve these materials wherever matching binaries remain downloadable, including mirrors and other delivery channels.

The source/license inventory and archive checks do not establish legal clearance for unrelated dependencies or validate a modified library on a device. The release evidence distinguishes completed checks from integration gates. Agent packages and Ubuntu preparation packages downloaded after installation are not bundled in the pinned base APK inputs; changes that preinstall them require a fresh inventory.

Original maintained source selectively reuses MIT Olea spike adapters, process ownership checks and Debian archive extraction. Experiment runners, fixtures, credentials and saved experimental data are not packaged.
