**OBSERVED**: Implemented journeys:

- Resumable onboarding: explicit Pi/Codex/Claude choice, explicit managed workspace selection/creation, Linux preparation without selecting Pi, STOP before chosen-agent installation, provider configuration, optional Android access review/skip and ready summary.
- Conversations: saved history, all-workspace/individual workspace filters, search, fixed agent identity, explicit draft agent/workspace controls, streaming text, selectable messages, expandable actual tool output, typed Working/Done/Stopped/Error/Needs you states and actual supported interaction choices.
- First send creates the selected-agent session, saves the draft, opens its runtime and sends once when that session is ready. A process recreation retains the draft rather than replaying it. Later sends clear only after runtime acceptance. Navigation does not stop another conversation.
- STOP all execution is separate from Stop turn. Saved-session reconnect, provider repair, installation retry and bounded runtime diagnostics have real controls. Messages and files remain visible when execution stops.
- Workspaces: creation, filtered conversation navigation, on-demand details, actual directory listings and selectable text previews. Previews reject paths outside the workspace, binary data and files larger than 256 KB. No seeded files.
- Management: Agents install/update, per-agent Providers with Responses/Anthropic descriptions, Environment start/STOP/status/diagnostics, phone-access entry, saved launch preference, light/dark/system appearance, About and actual bundled license text.
- Workspace terminals: independent runtime PTYs, create/select/close, raw input including Enter, Ctrl-C/interrupt, Esc/Ctrl/Tab/arrows, terminal resize, ANSI rendering, bounded runtime output, copy output, disconnected states and explicit environment start. Leaving terminal does not close it. Bundled xterm.js 5.5.0 runs in a network-blocked WebView serving only the app's bundled script/style; output is passed as quoted data.
