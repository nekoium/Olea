# Coarser paper dithering

**USER DECISION:** Make the dithering coarser and the background more like paper, keeping a copy of the current version. Source: “Make the dithering more coarse, the bg more like paper. Keep the copy of the current version.”

**OBSERVED:** This separate version preserves the gentle refinement's color grading and composition. It increases paper tooth and fiber visibility and adds coarse stochastic tonal dithering. The same tonal offset affects all three color channels to preserve photographic color relationships. Text and icon are drawn after the paper treatment and remain crisp.
